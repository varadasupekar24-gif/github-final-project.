# Simple Interest Calculator

This project is a simple interest calculator.

## Description
The calculator computes simple interest based on the principal amount, annual rate of interest, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal amount
- Rate of interest
- Time period

## Output
- Simple Interest
- Total Amount

## Usage
Enter the principal, rate, and time to calculate simple interest.
